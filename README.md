# Centwise

> 2026-10-13：已迁移出 **Flutter 版**，在 [`flutter/`](flutter/README.md) 文件夹（iPhone + Mac 预览，新 Bundle ID `com.koray.centwise`，从零开始，旧数据通过备份导入）。下面是原 SwiftUI 版的说明，代码保留未删。

一份可以自己修改的原生 iPhone 记账应用，附共用界面与账本核心的 Mac 预览版。独立实现，不使用 Money Pro 的代码、品牌或图片。当前是 **0.1 自用 MVP**，不是 Money Pro 全功能替代，也未上架。

## 品牌与保留的旧标识

应用对外名称为 **Centwise**（主屏幕名称、界面文案、备份类型显示名）。以下内部标识**有意保留**旧名，避免手机上已有账本和已导出的备份失联：

- Bundle ID `com.koray.qingledger`：改动会让 iPhone 把它当成另一个新 App，旧数据留在旧 App 里。
- 数据目录 `Documents/QingLedger`（Mac：`~/Library/Application Support/QingLedger/`）。
- 备份扩展名 `.qingledger` 与类型标识 `com.koray.qingledger.backup`，旧备份可直接导入。
- Xcode 工程 `QingLedger.xcodeproj`、target 与 scheme 名称（仅开发时可见；需要时可在 Xcode 中重命名）。

## 现在能做什么

- 新增、编辑、删除收入/支出；负数收支表示退款/冲销。
- 账户间转账：同时更新两端余额，不计入收支。
- 多分类金额分摊、备注、交易对象、日期、待入账状态。
- 新增/管理/归档账户、期初余额、余额核对调整；新增分类。
- 月度账单、搜索与类型筛选、收支总览、分类支出、近六个月趋势。
- 总支出/单分类月预算；每月重复，父分类不自动汇总子分类。
- 完整 `.qingledger` 备份导出、校验、预览后替换导入。
- 对本次 Money Pro 2.11.34 账本结构的只读迁移；保留所有源表原字段。

第一版只支持人民币。循环交易、旧计划执行、附件、外币、iCloud 同步、Face ID 应用锁、CSV 导入和上架流程尚未实现。分类暂支持查看与新增，未实现重命名/删除。转账是账本记录，**不会实际转移银行资金**。

## 先看可运行的预览

项目旁边的 `CentwisePreview.app` 可直接打开。已经设置为预览模式：初始是虚构演示账本，所有改动和导入只保存在内存中，退出后不保存，不会覆盖个人账本。

界面参考 Copilot Money（iOS）的设计语言：顶部是蓝色渐变与居中的 **Centwise** 品牌名，左侧齿轮打开“设置与备份”，右侧放大镜直达账单搜索；品牌名下方是可横向滚动的胶囊标签页（概览、分类、账单、账户），手机上也可以左右滑动切页。内容放在白色圆角卡片里，金额使用小号上标 ¥ 的圆体数字；分类有稳定的专属颜色与彩色标签；预算进度在 80% 内为绿色、接近上限为橙色、超出为红色。底部悬浮一个时间胶囊“‹ 今天 | 本月 | 近一年 ›”：默认显示今天，箭头按当前模式前后翻一天、一个月或 12 个月，再点一次已选中的项回到当前。“近一年”是含本月在内的滚动 12 个月：概览显示每月支出柱状图和月均虚线，以及近一年总支出、平均每月支出、总收入和平均每月结余（从第一笔记录所在月份起算，本月按整月计）；右下角是圆形“+”记账按钮。概览、分类、账单按所选时段统计，预算进度始终按整月计算。卡片不使用阴影，只保留细描边。兼容系统浅色/深色外观。Mac 预览编译同一份界面，便于检查手机布局，但不等于 iOS 真机渲染。

“记一笔”按 **金额 → 分类 → 保存** 排列：大金额直接输入、常用分类图标点选，账户默认第一个有效账户、日期默认今天；备注可选。退款、分摊、交易对象和待入账收进“更多选项”。编辑已有分摊时保持各项金额，切换类型导致分摊重设会先确认。新建记账时会直接弹出 App 内置的数字键盘（参考 Copilot：1–9、小数点、0、删除，长按删除清空），金额最多两位小数；键盘上方是“支出 | 退款”（收入为“收入 | 冲销”）切换和保存按钮。点备注等文字输入框时数字键盘自动收起，再点金额重新弹出。使用内置键盘也绕开了本次 iOS beta + 镜像环境下系统小数数字键盘初始化异常的问题；分摊金额等次要输入仍用系统数字/标点键盘。实际查看的 Mobbin 公开参考和设计依据见 [Mobbin-交互参考.md](Mobbin-交互参考.md)。

为贴近 Copilot 的交互，顶部导航、类型切换、分类点选和保存条改为自定义样式（替代之前的系统 TabView / 分段 Picker / 系统按钮）；账户菜单、日期选择、开关、折叠、表单、弹窗和文件选择仍使用 SwiftUI 系统组件。具体约定见 [iOS-原生组件约定.md](iOS-原生组件约定.md)，设计参考见 [Mobbin-交互参考.md](Mobbin-交互参考.md)。

在“设置 → 导入”可以选择桌面原备份文件夹下的“轻账迁移/个人账本-2026-10-08.qingledger”，查看自己的历史记录。导入有预览和确认步骤。**不要把预览当作正在使用的正式账本**；需要保留预览中修改的内容时，先手动导出备份。

## 数据安全与格式

- 所有业务金额是 `Int64` 整数分；输入最多两位小数。图表转为浮点数仅用于绘制。
- 核心校验账户/分类引用、重复编号、转账两端、分摊总额、币种、金额范围、日期有限性和预算重复。
- 本地持久化暂使用版本化 JSON + 原子替换，不是生产级数据库系统。日期使用 Foundation Codable 的 2001-01-01 参考秒，`schemaVersion = 1`。
- 保存前保留最近一次修改前的 `Backups/last-good.qingledger`；每天第一笔修改前保留一份每日快照；替换导入前额外保留一份独立快照。每日/导入快照暂不自动清理，需关注空间。
- 读取失败不会悄悄创建空账本覆盖原文件，而是暂停写入，允许明确恢复备份。
- iPhone 数据目录是 Documents/QingLedger，启用 Finder 文件共享。主文件及 last-good 写入使用 iOS 数据保护；不代表独立备份加密。
- 导出的备份是**明文**，包含私人财务数据与旧数据归档。建议保存在加密磁盘，不要放入公开 Git 仓库。`.gitignore` 排除 `.qingledger`、`.sql` 和构建产物。
- 不使用网络、云端、第三方 SDK 或分析服务。删除应用仍可能删除本机账本和快照；外部备份不可省略。

## 本次旧账本迁移

原始数据库始终只读，手机上的 Money Pro 未改动。转换文件在桌面原备份目录的“轻账迁移”中，**没有嵌入源码或安装包**。

核对结果：4,674 条有效交易 → 4,674 条Centwise记录；1 个账户；68 个原分类 + 1 个恢复的“未识别旧分类”；23 张源表原字段归档。来源主键、每笔金额、备注和日期逐条测试；分摊仍完整。

两条记录标为待核对：一条零金额旧类型 7 记录保留为余额调整；另一条分摊引用空分类编号，保留金额并建立未识别分类。这不是根据异常猜测改写历史金额。

账户 `sum` 字段暂按期初余额导入，当前余额只是数学推算，**尚未与旧应用或银行对账**。旧预算、计划、循环与同步状态仅归档、不执行。本导入器对未确认语义的交易类型、资产/负债关联或非人民币账户拒绝导入，不会默默跳过。

CLI 可以生成新的迁移副本和校验报告；不覆盖既有输出：

```sh
swift run LedgerTool migrate /path/database.sql /path/个人账本.qingledger
```

`.back` 是旧应用备份，不是本导入器的输入。源表归档不代表支持反向生成 Money Pro 备份。
